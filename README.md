# Colouring for little ones

A simple tracing & colouring page for toddlers (static web page, no ads, works offline after first load).

## Audio
- **Voice clips** (`audio/p*.mp3`, `audio/n-*.mp3`): pre-generated with Microsoft Edge neural text-to-speech
  (voice `en-US-JennyNeural`, rate −15 %, pitch −3 Hz) via the open-source `edge-tts` tool; 40 kbps mono.
- **Background music** (`audio/music.mp3`): an original music-box lullaby loop (C–Am–F–G, pentatonic melody)
  synthesised from scratch with Python/NumPy for this project. No third-party samples. Released as **CC0 / public domain**.
